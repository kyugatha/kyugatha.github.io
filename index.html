2. Awaaz ke tags

  
ElevenLabs mein script ke andar ye bracket wale shabd lagao. Inse awaaz robot jaisi nahi, kahani sunane wale jaisi lagti hai. Ye tags ElevenLabs ke v3 model ke saath sabse achha kaam karte hain.

  
    
  
    
    
    Tag lab
    
    
    Upar kisi tag par dabao, wo yahan cursor ki jagah lag jayega. Apni line likh kar try karo.
    
    
  
    
  
    Ek line pehle bina tag ke, phir tag ke saath generate karke suno. Farak khud samajh aa jayega.
    

    


    
  
    3. Master reel prompt
    
  
    Claude mein pehle Settings → Capabilities → Code execution and file creation on karo. Phir nayi chat mein MP3 attach karo aur ye prompt paste karo.
    
  
    Teen jagah bharni hain: SCRIPT (bina tags wala), STYLE (neeche se ek chuno) aur WATERMARK (apna handle). Yahan bharoge to prompt mein apne aap aa jayega.

    Zaroori baatein
    
  
    
    
    1
    Free plan ki sachchai
    ElevenLabs ka free plan sirf non-commercial kaam ke liye hai aur usme ElevenLabs ko credit dena hota hai. Reels se kamana ho ya ad chalana ho, to paid plan lena padega. Claude ka free plan bhi kuch kaam ke baad ruk jaata hai aur kuch ghante baad dobara chalta hai.
    
    
    2
    Claude awaaz nahi sunta
    Claude pause dhoondh kar timing lagata hai. Isliye script saath mein dena zaroori hai. Koi caption aage-peeche lage to second batao, wo theek kar dega.
    
    
    3
    Sudhaar saaf shabdon mein
    "18 second par chehra ajeeb hai, theek karo" jaisa batao. Second, cheez aur kya chahiye, teeno batao.
    
    
    4
    Post se pehle fact-check
    Claude se kaho: "is kahani ko source ke saath check karo." Dharmik kathaon ke kai roop hote hain, isliye reel mein granth ka naam likho.
    
  
    
  
    Aam problems aur unka hal
    
  
    
    
    Claude ne video file di hi nahi
    Settings → Capabilities mein "Code execution and file creation" on hai ya nahi, check karo. Phir usi chat mein likho: "MP4 file banakar do."
    
    
    Claude beech mein ruk gaya
    Free limit poori ho gayi hogi. Kuch ghante baad usi chat mein likho: "jahan ruke the, wahin se aage badho."
    
    
    Har scene mein kirdaar ka chehra alag hai
    Shuru mein hi bolo: "pehle har kirdaar ki ek tasveer banao, aur poori reel mein wahi use karo."
    
    
    Captions awaaz se aage-peeche hain
    Line aur second batao, jaise: "12 second wala caption 1 second pehle aaye." Claude theek kar dega.
    
    
    Awaaz robot jaisi lag rahi hai
    Tags badhao, aur lambi line ko do chhoti lines mein todo. [short pause] bhi kaam aata hai.
